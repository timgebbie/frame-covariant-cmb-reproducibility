# data/

**No empirical data are required at v1.0.0.**

v1.0.0 is an analytical reconstruction: every output in this bundle is generated
from the covariant recursion and from published equations, with no observational
input. Planck data, likelihoods and any calibration belong to v2.0.0.

*Calibration* at v2.0.0 means calibrating the solver against standard results. It
does **not** mean calibrating the amplitude of an effect.
