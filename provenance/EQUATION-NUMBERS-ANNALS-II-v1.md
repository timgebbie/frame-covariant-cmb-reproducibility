# Annals II equation numbers — resolved against the accepted manuscript

**Status: authoritative for this bundle. Generated, not transcribed.**

This file exists because an acceptance test anchored to the wrong numbering fails
in a way that looks like a physics error. Raised by the PI, 2026-10-06.

## What the numbers in this bundle are

They are the numbers **generated by the accepted Annals of Physics manuscript
source**, `sources/annals/cbrII.tex` in the project repository — not arXiv
numbers. The evidence is in the file itself:

* `\documentclass{ajour}` — the *Annals of Physics* journal class, with
  `ajour.cls`, `ajour.sty` and `ajourps.sty` beside it;
* its header block is dated **1 December 1999**, "gfre final revision based on
  Peter's final draft", under a heading reading **`Accepted -- the following
  changes made`**.

Numbering in that source is **generated** by LaTeX from 230 `\label` commands;
no equation number is hardcoded anywhere. So the mapping below is not a reading
of a PDF, it is the `.aux` file produced by compiling the accepted source. It was
produced by compiling `cbrII.tex` with its own class files in a scratch
directory; **nothing from `sources/` is copied into this bundle**, and the table
below is derived metadata rather than source text.
